Text Transform Comparison

ClassInputOutputUse Case
.text-uppercase Hello World HELLO WORLD Headings, navigation menus, emphasis
.text-lowercase HELLO WORLD hello world User input normalization, consistent styling
.text-capitalize hello world example Hello World Example Names, titles, proper nouns
Best Practices:
  • Use text-uppercase for navigation menus and buttons for emphasis
  • Use text-capitalize for names, titles, and proper nouns
  • Use text-lowercase for normalizing user input or email addresses
  • Combine with other text utilities like fw-bold for better visual hierarchy
  • Be consistent with text transform across your application
