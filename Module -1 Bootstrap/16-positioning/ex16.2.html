Position Utilities Reference

Class Property Use Case
.position-relative position: relative Parent container for absolute positioning
.position-absolute position: absolute Overlay elements (badges, tooltips)
.top-0, .bottom-0, etc. top: 0, bottom: 0, etc. Position absolute elements at edges
.start-0, .end-0 left: 0, right: 0 Position absolute elements horizontally
.translate-middle transform: translate(-50%, -50%) Center absolute positioned elements
