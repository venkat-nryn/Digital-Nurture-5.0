Bootstrap 5 + Sass Setup

Customizing Bootstrap using Sass with npm

Prerequisites

Node.js & npm

Make sure Node.js is installed on your system. npm comes with Node.js.

node --version
npm --version
Text Editor

VS Code, Sublime Text, or any code editor with Sass support.

Project Folder

Create a new directory for your Bootstrap Sass project.

Step-by-Step Setup

npm init -y

This creates a package.json file with default settings.

npm install bootstrap
npm install sass

This installs Bootstrap and the Sass compiler.

my-bootstrap-project/
├── scss/
│ └── custom.scss
├── css/
│ └── (compiled files go here)
├── node_modules/
├── index.html
└── package.json

Create scss/custom.scss with the following content:

// Custom variables
$primary: #6f42c1;
$secondary: #fd7e14;
$success: #198754;
$border-radius: 0.5rem;

// Import Bootstrap
@import "../node_modules/bootstrap/scss/bootstrap";

Add a script to package.json:

"scripts": {
  "sass": "sass --watch scss/custom.scss css/custom.css"
}

Run the compiler:

npm run sass

Complete package.json Example

{
  "name": "bootstrap-sass-project",
  "version": "1.0.0",
  "description": "Bootstrap 5 with Sass customization",
  "main": "index.js",
  "scripts": {
    "sass": "sass --watch scss/custom.scss:css/custom.css --style compressed",
    "sass-build": "sass scss/custom.scss:css/custom.css --style compressed"
  },
  "dependencies": {
    "bootstrap": "^5.3.0",
    "sass": "^1.69.0"
  }
}

HTML Template

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Bootstrap Sass Project</title>
  <link href="css/custom.css" rel="stylesheet">
</head>
<body>
  <div class="container">
    <h1>Custom Bootstrap with Sass</h1>
    <button class="btn btn-primary">Custom Button</button>
  </div>
  <script src="node_modules/bootstrap/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
