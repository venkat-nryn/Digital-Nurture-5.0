Bootstrap Variable Customization

Customizing primary color and border radius via Sass variables

What is Variable Customization? Bootstrap uses Sass variables for nearly all aspects of the framework. By overriding these variables before importing Bootstrap, you can create a completely custom theme!

Key Variables to Customize

Color Variables
  • $primary - Main brand color
  • $secondary - Secondary brand color
  • $success - Success/positive actions
  • $danger - Danger/error states
  • $warning - Warning/caution states
  • $info - Informational highlights
  • $light - Light backgrounds
  • $dark - Dark elements
Spacing & Border Variables
  • $border-radius - Default border radius
  • $border-radius-lg - Large border radius
  • $border-radius-sm - Small border radius
  • $btn-border-radius - Button border radius
  • $card-border-radius - Card border radius
  • $input-border-radius - Input border radius

Custom Sass File (_custom-variables.scss)

scss/_custom-variables.scss
// Custom color palette
$primary: #6f42c1; // Purple
$secondary: #fd7e14; // Orange
$success: #198754; // Green
$danger: #dc3545; // Red
$warning: #ffc107; // Yellow
$info: #0dcaf0; // Cyan
$light: #f8f9fa; // Light gray
$dark: #212529; // Dark gray

// Custom border radius
$border-radius: 1rem; // 16px default
$border-radius-lg: 1.5rem; // 24px for large elements
$border-radius-sm: 0.5rem; // 8px for small elements

// Component-specific radius
$btn-border-radius: $border-radius;
$card-border-radius: $border-radius;
$input-border-radius: $border-radius-sm;

// Theme colors map
$theme-colors: (
  "primary": $primary,
  "secondary": $secondary,
  "success": $success,
  "danger": $danger,
  "warning": $warning,
  "info": $info,
  "light": $light,
  "dark": $dark
);

Main Sass File (custom.scss)

scss/custom.scss
// Import custom variables first
@import "custom-variables";

// Option A: Include all of Bootstrap

Compilation Commands

One-time Compile
sass scss/custom.scss css/custom.css --style compressed
Watch Mode (Auto-compile)
sass --watch scss/custom.scss:css/custom.css

npm Scripts Configuration

"scripts": {
  "sass:watch": "sass --watch scss/custom.scss:css/custom.css",
  "sass:build": "sass scss/custom.scss:css/custom.css --style compressed",
  "sass:dev": "sass scss/custom.scss:css/custom.css --style expanded --source-map"
}

Run with:

npm run sass:watch

Troubleshooting Common Issues
  • Variables not applying: Make sure custom variables are imported BEFORE Bootstrap
  • Sass compilation errors: Check that all dependencies are installed correctly
  • Changes not showing: Clear browser cache or do a hard refresh (Ctrl+Shift+R)
  • Path issues: Use correct relative paths when importing Bootstrap
  • Missing !default flag: Variables must be defined before Bootstrap imports to override defaults
Best Practices for Sass Customization:
  • Create a separate _variables.scss file for your custom variables
  • Use !default flag when creating custom variable files
  • Only import Bootstrap components you actually use to reduce file size
  • Use source maps during development for easier debugging
  • Compress CSS for production using --style compressed
  • Version control your Sass files, not the compiled CSS
