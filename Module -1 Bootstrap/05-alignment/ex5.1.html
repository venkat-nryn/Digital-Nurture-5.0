Key Concepts:
  • justify-content-* controls horizontal alignment of columns within a row
  • align-items-* controls vertical alignment of columns within a row
  • Use h-100 class to ensure the row takes full height of container
  • Combine both classes for perfect centering: justify-content-center align-items-center
