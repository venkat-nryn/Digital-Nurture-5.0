CSS Folder Purpose

Contains all stylesheet files for Bootstrap's visual components

FilePurposeUse Case
bootstrap.min.cssComplete Bootstrap stylesFull framework usage
bootstrap-grid.min.cssGrid system onlyWhen only grid needed
bootstrap-utilities.min.cssUtility classes onlyCustom components + utilities
bootstrap-reboot.min.cssReset/normalize stylesBase styling only

JS Folder Purpose

JavaScript plugins for interactive components

Bundle Includes:
  • Modal
  • Dropdown
  • Tooltip
  • Popover
  • Collapse
  • Carousel
  • Tab
  • Alert
Note: bootstrap.bundle.js includes Popper.js (required for tooltips and popovers)
