Four Column Grid Explanation
Grid Classes Used:
  • col-12 - Full width on mobile (extra small screens <576px)
  • col-sm-6 - 2 columns on small screens (≥576px)
  • col-md-4 - 3 columns on medium screens (≥768px)
  • col-lg-3 - 4 columns on large screens (≥992px)
Breakdown per breakpoint:
Screen SizeBreakpointColumns per rowClass used
Mobile<576px1 columncol-12
Small Tablet≥576px2 columnscol-sm-6
Tablet≥768px3 columnscol-md-4
Desktop≥992px4 columnscol-lg-3
Formula: Each column width = 12 ÷ number of columns.
4 columns: 12 ÷ 4 = 3 → col-*-3
