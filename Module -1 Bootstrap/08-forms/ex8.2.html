About form-floating

The .form-floating class creates floating labels that animate when the input is focused or has content.

How it works:
  • Labels float above the input
  • Saves vertical space
  • Modern UI pattern
  • Works with validation states
Note: For floating labels to work properly, the placeholder attribute is required.
